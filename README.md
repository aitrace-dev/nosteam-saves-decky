# NoSteam companion

Standalone Linux app for managing non-Steam saves, direct game transfers, and your devices.
Decky is no longer required. The repository name is historical.

See [desktop/README.md](desktop/README.md) for installation, operation and validation.
The hosted service is https://nosteam.bluggie.com; server code is maintained separately.
This public repository contains only the client. The new backend endpoints must be deployed
before device reporting and game transfers can work with the hosted service.

Existing launch wrappers, local saves, pending uploads, conflict copies and backups are
retained. Installing the companion does not remove an existing device installation.
