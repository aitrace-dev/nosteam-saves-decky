# Project instructions

Use GitHub account `aitrace-dev` and repository `aitrace-dev/nosteam-saves-decky`.
This client-only repository is intentionally public. Keep the separate
`aitrace-dev/nosteam-saves` server repository private. Never copy server files, credentials,
`.existing-env`, `.secrets/`, deployment settings or private-repository history here.
Verify the authenticated account and remote owner before pushing.

The plugin is a developer alpha. Do not describe account pairing, bundled agent installation
or Decky Store approval as complete until each is implemented and verified.
